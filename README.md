# FocusFlow OS

FocusFlow OS is an immersive deep-focus productivity platform designed to help users enter distraction-free work sessions using cinematic ambience, weather-aware environments, gamification, and focus analytics.

---

# Features

- Flip Clock Timer
- Deep Focus Mode
- Weather Integration
- Ambient Soundscapes
- Dynamic Themes
- Fireworks Celebrations
- Productivity Analytics
- Gamification System

---

# Tech Stack

## Frontend

- Next.js
- Tailwind CSS
- Framer Motion

## Backend

- Node.js
- Express.js

## Database

- MongoDB Atlas
